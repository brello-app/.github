# Security Policy

Brello helps developers protect their API keys, so we take security reports seriously.

## Reporting a vulnerability

Please do not open a public issue for security problems.

Report vulnerabilities through one of these:

- GitHub private vulnerability reporting (the "Report a vulnerability" button in the Security tab)
- Email: security@brello.app

Please include:

- A description of the issue and its impact
- Steps to reproduce
- Any relevant versions, URLs, or code

## What to expect

- We'll acknowledge your report within 72 hours.
- We'll keep you updated as we investigate and fix it.
- Once it's fixed, we're happy to credit you if you'd like.

Please give us a reasonable amount of time to fix the issue before disclosing it publicly.
