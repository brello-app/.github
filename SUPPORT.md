# Getting help with Brello

Not sure where to go? Here's the quickest path for each kind of question.

| What you need                         | Where to go                                                |
| ------------------------------------- | ---------------------------------------------------------- |
| Questions, ideas, or feature requests | [Feedback board](https://brello.app/feedback)              |
| A bug in one of our open-source repos | Open an issue in that repo                                 |
| A bug in the Brello dashboard or Scan | [Feedback board](https://brello.app/feedback) (Bug Report) |
| A security vulnerability              | **security@brello.app** (please don't post it publicly)    |
| Anything else                         | [support@brello.app]                                       |

**Beta testers:** you can reach me directly in your private Discord channel, any time.

**Please never share API keys** (Brello or provider keys) in issues, the feedback board, or email. If you think one of your keys has leaked, revoke it with your provider first, then reach out.

— Dan, founder of Brello
