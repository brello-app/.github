# Brello

**Know the moment your AI API key is misused.**

Brello watches your OpenAI, Anthropic, and Gemini API keys so you find out about leaks and unusual usage before the bill does. Built for developers running real projects on AI APIs.

## What we're building

- **Usage monitoring**: See requests, tokens, and cost per key and per model.
- **Unusual usage alerts**: Get notified on sudden spikes, often the first sign of a leaked key.
- **Open-source SDK**: A lightweight wrapper that never blocks your AI calls, even if Brello is down. _(Coming soon)_
